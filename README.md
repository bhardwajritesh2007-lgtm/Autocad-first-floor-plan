# Mirror, Stretch & Scale Commands in AutoCAD

## 📌 Overview
This repository explains the use of *Mirror, **Stretch, and **Scale* commands in AutoCAD.  
These commands are essential for editing and modifying drawings efficiently without redrawing objects.

The examples are demonstrated using a *First Floor Plan*, commonly used in civil engineering drawings.

---

## 🛠️ Commands Explained

### 1️⃣ Mirror Command
The *Mirror* command is used to create a symmetrical copy of objects across a defined centerline.

#### 🔹 Uses:
- Creating symmetrical rooms
- Copying doors and windows
- Maintaining uniformity in floor plans

#### 🔹 Steps:
1. Type MIRROR and press *Enter*
2. Select the objects
3. Specify the mirror line
4. Choose *Yes/No* to delete the original object

### 2️⃣ Stretch Command
The *Stretch* command is used to change the shape or size of objects by stretching them in one direction.

#### 🔹 Uses:
- Extending walls
- Changing room sizes
- Adjusting openings without redrawing

#### 🔹 Important Note:
- Always use a *crossing window (green selection)* for stretch to work properly.

#### 🔹 Steps:
1. Type STRETCH and press *Enter*
2. Select objects using crossing window
3. Specify base point
4. Specify new position

### 3️⃣ Scale Command
The *Scale* command is used to increase or decrease the size of objects proportionally.

#### 🔹 Uses:
- Resizing furniture
- Adjusting symbols
- Scaling text or blocks

#### 🔹 Steps:
1. Type SCALE and press *Enter*
2. Select objects
3. Specify base point
4. Enter scale factor (e.g., 0.5 or 2)

## 🔄 Additional Editing Commands
After using *Mirror* or *Scale*, the following commands are often required:
- MOVE – To reposition objects
- ROTATE – To align objects correctly
